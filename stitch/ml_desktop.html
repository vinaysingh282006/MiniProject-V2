Formal Theoretical Foundations

Training Formulations & Regularization

Mathematical optimization framework designed to mitigate transient class imbalance and ensure numerical stability during edge quantization.

OBJECTIVE FUNCTION γ=2.0, α=0.25

Focal Cross-Entropy Loss

Suppresses gradient magnitude from abundant static/walking segments, focusing backpropagation on fleeting fall transitions.

L_FL(p_t) = -α_t · (1 - p_t)^γ · log(p_t)
where p_t = p if y=1 else (1 - p)
Hard sample weight +340% gradient bias
SPARSITY PENALTY λ_1=1e-5, λ_2=1e-4

Elastic Net Regularization

Combines L1 Lasso penalty to enforce zero-weight pruning for edge compaction with L2 Ridge decay to bound gradient explosion.

R(W) = λ_1 ∑|w_ij| + 0.5·λ_2 ∑(w_ij)^2
Prunes 26.4% near-zero weights
Sparsity achieved 26.4% zero-coefficients
GRADIENT COMPUTATION T=64 Frames

Chain Rule DAG & BPTT

Temporal gradient accumulation unrolled across Gated Recurrent Unit hidden states over sequential Doppler frames.

∂L / ∂W_h = ∑_{t=1}^T (∂L_t / ∂h_t) · ∏_{k=2}^t (∂h_k / ∂h_{k-1})
Norm-clipped threshold: ||g|| ≤ 1.0
Clip threshold ||g|| ≤ 1.0
CONVERGENCE SCHEDULE Adam Optimizer

Cosine Annealing Schedule

Smooth cyclical learning rate decay without restarts, preventing premature local minima traps on high-frequency noise.

η_t = η_min + 0.5(η_max - η_min)(1 + cos(π·t / T_max))
η_max=1e-3, η_min=1e-6, 120 Epochs
Mini-batch size 32 Spectrograms
