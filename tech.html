RADAR PRINCIPLE

1. FMCW Chirp & Beat Frequency Physics

Frequency-Modulated Continuous-Wave radars emit linear frequency chirps. The delay between transmission and reflection produces a beat frequency $f_b$.

Range Equation:
R = (c · Tc · fb) / (2B)
c = Speed of Light ≈ 3 × 108 m/s. The propagation speed of electromagnetic mmWave radio waves.
B = Chirp Bandwidth 250 MHz on 24 GHz (ΔR = c/2B ≈ 60 cm), and up to 4 GHz sweep on 60 GHz (ΔR ≈ 3.75 cm resolution).
Doppler Velocity (vr) Calculated from the phase shift across consecutive chirps: Δφ = (4π · vr · Tc) / λ.

  • • Atmospheric Damping: Higher absorption in oxygen (O2 band), eliminating false targets through exterior walls.
  • • Power Consumption: ~150 mA peak @ 5.0V DC.
BINARY PROTOCOL

3. The 30-Byte LD2452 Frame & Adaptive Parser

The HLK-LD2452 delivers fixed 30-byte telemetry frames at 256,000 bps. The LD6003D adaptive parser auto-detects Hi-Link binary (AA FF ... 55 CC) and SY packet structures (53 59 ... 54 43).

30-BYTE FRAME STRUCTURE:
AA FF 03 00
HEADER (4B)
X(2) Y(2) Spd(2) Dist(2)
TARGET 1 (8 BYTES)
X(2) Y(2) Spd(2) Dist(2)
TARGET 2 (8 BYTES)
X(2) Y(2) Spd(2) Dist(2)
TARGET 3 (8 BYTES)
55 CC
TAIL (2B)
Bit 15 Sign Convention:
Coordinates in the LD2452 payload are 16-bit signed integers in millimeters. Bit 15 indicates sign:
int16_t x = (raw_byte_high & 0x80) ? -((raw_byte_high & 0x7F) << 8 | raw_byte_low) : ((raw_byte_high << 8) | raw_byte_low);
SILICON ROUTING

4. ESP32 GPIO Matrix & Hardware UART Routing

Unlike standard microcontrollers, the ESP32 GPIO Matrix allows hardware UART peripherals to be routed to any non-flash pin. Hence, Serial2.begin(115200, SERIAL_8N1, 25, 26) is true hardware buffered UART with DMA support.

Hardware UART1

GPIO16 (RX) & GPIO17 (TX) assigned to LD2452 @ 256,000 bps. High baud eliminates frame latency.

Hardware UART0 Remap

GPIO25 (RX) & GPIO26 (TX) assigned to LD6003D @ 115,200 bps. Leaves USB Serial programming unaffected.

× FORBIDDEN: GPIO 9 & 10

Tied directly to the on-module SPI Flash. Attempting to use them causes immediate CPU crash and boot loop.

STATE-SPACE ESTIMATION ENGINE

6. Dual-Sensor Asynchronous Kalman Filter Architecture

Continuous-discrete kinematic state-space estimator running on ESP32 Core 1. Merges noisy 24 GHz measurements ($R_{24}$) and high-resolution 60 GHz measurements ($R_{60}$) with Mahalanobis spatial gating.

STATE: [X: 0.00m, Y: 0.00m, Vx: 0.00, Vy: 0.00] K = 0.500 Tr(P) = 0.420
24 GHz Measurement & Ellipse (R24) 60 GHz Measurement & Ellipse (R60) A Priori Prediction (x̂-) Optimal Kalman State (x̂)
1. KINEMATIC MOTION MODEL (F, Q)
xk = [px, py, vx, vy]T
F = [[1, 0, Δt, 0], [0, 1, 0, Δt], [0, 0, 1, 0], [0, 0, 0, 1]]
x̂k- = F x̂k-1,   Pk- = F Pk-1 FT + Q

Sample interval Δt = 0.10s. The continuous white-noise acceleration model Q (q = 0.25 m²/s³) accommodates sharp human turns and sudden halting without lag or overshooting.

2. ASYNCHRONOUS UPDATE (H, R)
H = [[1, 0, 0, 0], [0, 1, 0, 0]]
R24 = diag(0.12, 0.12) • R60 = diag(0.02, 0.02)
zk ∈ {z24, z60} (Sequential Asynchronous Arrival)

Sensors transmit frames over separate FreeRTOS UART queues. Rather than waiting for synchronization, the filter applies a sequential update with the specific sensor's noise covariance whenever a packet arrives.

3. GAIN (K) & MAHALANOBIS GATING
Kk = Pk- HT (H Pk- HT + R)-1
x̂k = x̂k- + Kk (zk - H x̂k-)
dM2 = (zk - H x̂-)T S-1 (zk - H x̂-) ≤ 9.21

When 60G reports, K automatically shifts 85% confidence to its fine millimeter position. Returns exceeding the 99% χ² confidence ellipsoid (dM2 > 9.21) are rejected as multipath clutter.

ESP32 Microsecond Kalman Execution (≤ 1.8 μs on Xtensa Core 1) Fixed 4×4 Float Matrix 
// High-performance 2D Kinematic Kalman Filter for Dual Radar Fusion
void kalmanUpdate(TargetKF &kf, float zx, float zy, float sigmaR) {
  // 1. Innovation residual
  float yx = zx - kf.px;
  float yy = zy - kf.py;

  // 2. Innovation covariance S = P + R
  float Sx = kf.Pxx + (sigmaR * sigmaR);
  float Sy = kf.Pyy + (sigmaR * sigmaR);

  // 3. Mahalanobis distance gating check (chi-square 2-DOF at 99%)
  float dM2 = (yx * yx) / Sx + (yy * yy) / Sy;
  if (dM2 > 9.21f) return; // Reject multipath or fan clutter

  // 4. Optimal Kalman gain K = P / S
  float Kx = kf.Pxx / Sx;
  float Ky = kf.Pyy / Sy;

  // 5. State correction
  kf.px += Kx * yx;
  kf.py += Ky * yy;
  kf.vx += (Kx / 0.10f) * yx * 0.25f;
  kf.vy += (Ky / 0.10f) * yy * 0.25f;

  // 6. Covariance update P = (1 - K) * P
  kf.Pxx *= (1.0f - Kx);
  kf.Pyy *= (1.0f - Ky);
}

LD2452 30-Byte RingBuffer Parser Skeleton RingBuffer 
bool parseLD2452Frame(uint8_t *buf, int len, Target24 &tgt) {
  // Validate sync header AA FF 03 00 and tail 55 CC
  if (buf[0] != 0xAA || buf[1] != 0xFF || buf[2] != 0x03 || buf[3] != 0x00) return false;
  if (buf[28] != 0x55 || buf[29] != 0xCC) return false;

  // Extract Target 1: int16 millimeters (Bit 15 = sign)
  int16_t rawX = (int16_t)(buf[4] | (buf[5] << 8));
  int16_t rawY = (int16_t)(buf[6] | (buf[7] << 8));
  tgt.x = rawX / 1000.0f;
  tgt.y = rawY / 1000.0f;
  return true;
}

void vFusionTask(void *pvParameters) {
  for (;;) {
    float dx = tgt24.x - tgt60.x;
    float dy = tgt24.y - tgt60.y;
    float dist = sqrtf(dx * dx + dy * dy);

    if (dist <= 0.50f) {
      // Torso association locked: 99% confidence
      fused.x = 0.45f * tgt24.x + 0.55f * tgt60.x;
      fused.y = 0.50f * tgt24.y + 0.50f * tgt60.y;
      fused.conf = 99.4f;
    }
    vTaskDelay(pdMS_TO_TICKS(100));
  }
}
