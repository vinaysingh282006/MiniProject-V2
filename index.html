CALCULATED EVERY 100 MS

The fusion algorithm in 30 seconds.

A deterministic greedy association pipeline that converts raw polar clutter into an authoritative tracking coordinate.

1. EUCLIDEAN GATING
dd ≤ 0.50 m

If the distance between 24G and 60G returns is ≤ 0.50m, the target is confirmed and elevated to 99% confidence.

2. ASYMMETRIC WEIGHTING
X = 0.45·X24 + 0.55·X60

60 GHz receives higher weight (0.55) along azimuth for its narrower beam, while distance is balanced 50/50.

3. ASYMMETRIC LATCH
Fallback: 5.000s

If 60G drops during zero-motion pauses, 24G energy gates maintain the track for 5 seconds without flickering off.

// FMCW Radar Range Equation
R = (c · Tc · fb) / (2 · B)

// Euclidean Association & Linear Position Interpolation
float dd = sqrt(sq(X24 - X60) + sq(Y24 - Y60));
if (dd <= 0.50f) {
  fused.x = 0.45f * X24 + 0.55f * X60;
  fused.y = 0.50f * Y24 + 0.50f * Y60;
  fused.confidence = 99;
}
