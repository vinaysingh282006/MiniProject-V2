SHORT-TIME FOURIER TRANSFORM (STFT)

1. Micro-Doppler Velocity Signature Extraction

The 60 GHz radar extracts involuntary kinematic limb swings and chest wall respiration from phase shifts over sliding 64-sample Hamming windows.

CLASS 00 • WALKING Locomotion Kinematics Torso bulk velocity (±1.2 m/s) with prominent arm and leg swing harmonic envelopes (±2.5 m/s).
CLASS 01 • SEATED VITALS Thoracic Respiration Sub-Doppler micro-motion (0.15–0.35 Hz, ±0.04 m/s) tracking 0.2mm chest wall displacement during breathing.
CLASS 02 • FALL EVENT Acute Transient Drop Sudden vertical acceleration spike exceeding 4.2 m/s followed by prolonged post-impact zero-Doppler silence.
CLASS 03 • CLUTTER Rigid Oscillating Fan Fixed integer harmonic spikes from metallic blades without organic biological variance; automatically rejected.

TRAINING PIPELINE & MATHEMATICS

3. Loss Functions, Regularization & Backpropagation

Rigorous mathematical handling of training dynamics: solving acute class imbalance with Focal Loss, inducing weight sparsity for flash storage via L1 Lasso, and tracking signal quality with PSNR.

TRAINING DYNAMICS (120 EPOCHS) COSINE ANNEALING
Learning Rate (α) 0.0010
L1 Penalty (λ1) 0.00010
L2 Decay (λ2) 0.00010
Weight Sparsity: 26.4% Signal PSNR: 28.42 dB
FOCAL LOSS (CLASS IMBALANCE)
LFL = -αt (1 - pt)γ log(pt)

Setting γ=2.0 down-weights easy non-fall samples by factor (1-pt)2, focusing gradient updates on rare acute fall impacts.

ELASTIC NET REGULARIZATION
Lreg = λ1 ∑ |W| + (λ2 / 2) ∑ W2

L1 (Lasso) forces 26.4% of weights to exactly zero for zero-overhead flash pruning; L2 (Ridge) restricts weight magnitudes against gradient explosion.

BACKPROPAGATION THROUGH TIME (BPTT)
∂L / ∂W = ∑ (∂L / ∂ht) · (∂ht / ∂zt) · (∂zt / ∂W)

Gradients propagate through 64 temporal frames with gradient norm clipping at 1.0 to guarantee stable convergence in recurrent GRU gates.

TENSOR ALLOCATION

5. Post-Training Quantization (FP32 → INT8)

Full integer symmetric quantization maps float32 tensors to 8-bit integers via scale factor $S$ and zero-point offset $Z$: $q = \text{clamp}\left(\text{round}\left(\frac{x}{S}\right) + Z, -128, 127\right)$, reducing memory by 75% with under 0.3% loss in accuracy.
