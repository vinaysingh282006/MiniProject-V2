DIGITAL OSCILLOSCOPE & LOGIC ANALYZER

Real-Time Hardware Bus Timing & Interrupt Trace

Live multi-channel logic analyzer capture displaying asynchronous UART DMA packets, VSPI 40MHz display clocks, capacitive touch interrupts, and piezo alarm triggers.

1. UART1 256,000 BAUD (LD2452)

Fixed 30-byte frames ingest in 1.17 ms window. Hardware FIFO buffer prevents frame corruption during dual-core FreeRTOS task switches.

2. UART0 115,200 BAUD (LD6003D)

Continuous point-cloud bursts parsed on Core 0. DMA ring-buffer queues validated payloads into shared memory without CPU polling.

3. VSPI 40MHz CLOCK ARBITRATION

TFT_CS (GPIO15) and TOUCH_CS (GPIO21) are mutually exclusive. Hardware bus arbitration guarantees screen DMA never collides with touch polling.

4. PEN IRQ & PIEZO ALARM PWM

TOUCH_IRQ (GPIO22) triggers on falling edge (< 5 μs latency). GPIO32 generates clean 2.7 kHz resonant square waves on geofence breach.

FIRMWARE FLASHING GUIDE

PlatformIO Deployment in 4 Steps

01
Clone Repository & Open in VS Code

Ensure PlatformIO IDE extension is installed in VS Code. Open the project root folder.

02
Configure Network in Config.h

Set DEFAULT_WIFI_SSID and DEFAULT_WIFI_PASS for LAN connection, or leave defaults for SoftAP.

03
Compile & Upload Firmware

Run pio run -t upload to flash both FreeRTOS tasks to the ESP32.

04
Monitor Serial Diagnostics

Run pio device monitor @ 115200 baud to view boot logs, SPI check, and IP address allocation.

DIAGNOSTIC MATRIX

Troubleshooting Hardware Issues

Root Cause: SPI initialization failure, incorrect CS/DC pin definition, or insufficient 5V backlight current.

Remedy: Verify SPI wiring: CS=GPIO15, DC=GPIO2, RST=GPIO4, Backlight=GPIO27. Check that the 5V supply provides ≥ 180 mA dedicated to the screen backlight. Ensure TFT_eSPI User_Setup.h selects driver #define ILI9488_DRIVER.
Root Cause: TX/RX crossed lines, baud rate mismatch, or floating BOOT pin on LD6003D.

Remedy: Remember sensor TX connects to ESP32 RX. Check baud: LD2452 requires 256,000 bps on UART1; LD6003D requires 115,200 bps on UART0. On LD6003D, verify pin BOOT/P19 is tied securely to GND. Switch to "VIEW RAW HEX" on the TFT to inspect live incoming byte sync headers.
Root Cause: Resistive touch calibration mismatch between landscape orientation and physical sensor matrix.

Remedy: Check touch_calibrate() values inside Config.h. If X and Y are inverted, update the rotation mapping flag tft.setRotation(1) or swap calibration extremes CALIBRATION_X_MIN and CALIBRATION_X_MAX.
Root Cause: Inrush current during simultaneous 24G + 60G radar chirping exceeding power supply limits (draw spikes to ~750 mA).

Remedy: Do NOT power the entire rig from a laptop USB port (limited to 500 mA). Connect a dedicated 5V 2A external DC power supply. Solder a 220–470 μF electrolytic capacitor plus a 0.1 μF ceramic capacitor directly across the 5V and GND pins of the ESP32.
