## 4. Hardware Specifications & Project Facts

- **Controller:** Espressif ESP32-WROOM-32E (Xtensa Dual-Core 32-bit, 240 MHz), PlatformIO.
- **24 GHz Radar:** Hi-Link HLK-LD2452, FMCW, UART1 @ 256,000 bps, ESP32 GPIO16 (RX) / GPIO17 (TX), up to 3 targets, 10 Hz rate, 1T2R microstrip patch array, ~126 mA current, wavelength $\lambda \approx 12.5\text{ mm}$, penetrates drywall, glass, and clothing.
- **60 GHz Radar:** Hi-Link HLK-LD6003D (ADT6101P, ARM Cortex-M3), FMCW, UART0 remap @ 115,200 bps, ESP32 GPIO25 (RX) / GPIO26 (TX), 3–4 targets, 10 Hz rate, 2T2R MIMO virtual array, wavelength $\lambda \approx 5.0\text{ mm}$, high angular resolution, sub-millimeter chest wall respiration tracking. BOOT/P19 grounded.
- **Coverage Envelope:** Radial depth up to 6.0 meters, Azimuth FOV &plusmn;60° horizontal (120° total sector), &plusmn;30° vertical.
- **Local Embedded Display:** 3.5" SPI TFT (ILI9488, 480&times;320 landscape) + XPT2046 resistive touch controller on shared VSPI bus:
  - Shared Lines: MOSI (GPIO23), SCK (GPIO18), MISO (GPIO19)
  - Dedicated Lines: TFT CS (GPIO15), DC (GPIO2), RST (GPIO4), Backlight (GPIO27), Touch CS (GPIO21), Touch IRQ (GPIO22)
  - Optional Intrusion Alarm Buzzer: GPIO32 (PWM)
- **Power Budget:** Peak consumption ~670–750 mA. Requires a dedicated external 5V 2A power supply (never standard 500mA laptop USB ports) paired with 220–470 &mu;F electrolytic + 0.1 &mu;F ceramic decoupling capacitors across 5V and GND.
- **GPIO Matrix Constraint:** GPIO 9 and 10 are tied to internal SPI Flash. They are strictly forbidden from firmware use.

## 5. Live Hardware WebSocket Protocol

The simulator on [`simulation.html`](file:///c:/Users/Vinay%20Singh/Desktop/MiniProject-main/simulation.html) includes a live bridge input (`ws://<ip>/ws`). If an active ESP32 is reachable, it parses incoming telemetry packets in the following JSON format:

```json
{
  "timestamp": 128450,
  "count": 2,
  "targets": [
    {
      "id": 1,
      "x": 0.22,
      "y": 3.42,
      "vx": 0.05,
      "vy": 0.12,
      "dist": 3.427,
      "conf": 99.4,
      "state": "FUSED_LOCK"
    },
    {
      "id": 2,
      "x": -1.45,
      "y": 2.10,
      "vx": -0.10,
      "vy": 0.02,
      "dist": 2.551,
      "conf": 75.0,
      "state": "24G_SINGLE"
    }
  ],
  "geofence_breach": false,
  "heap_free": 184512
}
```
If the WebSocket server is offline, the browser gracefully retains its internal virtual simulation engine without breaking.
